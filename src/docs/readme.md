## API REFERENCE 

## PRODUTOS    

#### GET/PRODUTOS
- **Descrição**: Obtém uma lista de produtos 
- **Response**: Lista de produtos 

#### POST/Produtos 
- **Descrição** : Cria um novo produto 
- **Body** :

```
{
    "idProduto":"Mesa"
    "idPreco": 0.00
}

```
- **Response** :
```
{
    "message": "Produto cadastrado com sucesso!"
}
```
